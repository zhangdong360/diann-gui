watch_daemon {diann.gui}R Documentation

邮件通知守护进程

Description

轮询状态文件中的待通知作业, 作业离队后发送完成邮件。 通常由应用自动以 nohup 派生, 无需手动调用。

Usage

watch_daemon(state = NULL, pidfile = NULL, interval = 60,
             idle_exit_sec = 86400, once = FALSE)

Arguments

state

通知状态文件路径 (默认取包配置)

pidfile

pid 文件路径 (默认取包配置)

interval

轮询间隔秒 (下限 5)

idle_exit_sec

空闲自退秒数

once

TRUE = 只执行一轮检查即返回
